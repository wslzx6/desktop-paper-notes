# 桌面便签界面设计系统

依据 UI/UX Pro Max 的 design-system-first 工作流整理。产品类型是常驻后台的 Windows 桌面生产力工具，界面风格采用紧凑、安静、纸张感轻量的工作台。

## 信息层级

1. 当前便签的内容编辑是第一视觉层级。
2. “完成并锁定”和“在桌面编辑”是两个场景中的主操作，每个区域只保留一个实心主按钮。
3. 便签列表负责选择，颜色只作为识别标记，不铺满卡片。
4. 备份、恢复和开机启动放在底部工具区，保持可见但降低视觉权重。

## 设计令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Ink | `#222824` | 标题、正文 |
| Accent | `#2A5B45` | 主按钮、选中边框、品牌标记 |
| Accent soft | `#E2EDE6` | 选中卡片、弱提示 |
| Canvas | `#EFF1ED` | 侧栏与窗口背景 |
| Surface | `#FCFCF9` | 编辑区、工具区 |
| Soft surface | `#F5F7F3` | 输入框、Markdown 工具条 |
| Border | `#D7DCD6` | 1px 分隔线和输入边界 |
| Muted | `#667069` | 状态、尺寸等辅助信息 |
| Danger | `#9C453F` | 删除操作 |

字体使用 Microsoft YaHei UI。正文 9–12pt，区块标题 11–14pt。间距以 8px 为基准，常用间距为 8、16、24、32px。圆角限定为 6–7px，避免过度胶囊化。

## 控件规则

- 普通按钮使用系统箭头光标；文本输入使用 I-beam；拖拽区域和缩放手柄保留对应操作光标。
- 所有按钮在 hover、pressed、disabled 和键盘 focus 状态下保持尺寸不变，避免布局跳动。
- 主按钮使用深绿底白字；次按钮使用浅底、1px 边框；危险操作只使用危险文字色。
- 颜色选项使用圆形色点和明确的选中环，同时提供工具提示和键盘操作。
- 便签卡片用标题、正文摘要、尺寸/透明度三层信息，选中态使用浅绿底和深绿细边框。
- Markdown 格式栏保持单行、固定高度；每个按钮有工具提示，不用装饰性图标混用。
- Markdown 格式栏使用统一线宽的本地矢量图标，并按标题/行内格式、内容块、列表/链接分组；悬停和按下状态使用浅绿色圆角底，不改变按钮尺寸。
- 字号使用紧凑的减号/数值/加号步进器，透明度使用自绘细轨滑块，布尔设置使用开关，避免混入平台默认控件的旧式外观。

## 窗口结构

- 78px 顶栏：产品标记、名称、保存状态、完成并锁定。
- 280px 左侧栏：便签数量、新建、便签列表。
- 主编辑区：标题、Markdown 工具、正文、颜色/字号、透明度、桌面操作。
- 60px 底栏：开机启动、导入导出、撤销删除。

## 验收

- 主要任务无需滚动即可完成。
- 800% 以内的窗口宽度变化不遮挡主操作；最低窗口尺寸为 860 × 640。
- 文本与背景保持清晰对比；辅助文字不承担关键含义。
- 鼠标停在普通按钮上不会切换成白色手形光标。
